# remove-watermark — 去掉图片上的水印 / 角标

核心工具是 [scripts/remove_watermark.py](scripts/remove_watermark.py)：定位水印区域 → 把整块像素当成「未知」重算 → 用指标验证。
先读这页，别一上来就手写脚本。

## 先判断能不能「无痕」

| 水印压在哪 | 结果 |
| --- | --- |
| 纯色 / 平滑渐变 / 虚化背景 | 能做到肉眼无痕（框内高频残差 < 2/255） |
| 头发、人脸、文字、复杂纹理 | 调和填充只会糊出一团；改用 `cv2.inpaint`(TELEA/NS) 或生成式修补 |

整幅平铺的半透明水印可以试反解：`bg = (obs - α·c) / (1 - α)`（c 为水印颜色，α 为透明度）。α 未知时先在背景已知处估一个。

## 必须用带 PIL / numpy 的 python

本机 `/opt/homebrew/bin/python3`、`/usr/bin/python3` **都没有 PIL**。用 Codex 运行时自带的那个（路径由 `load_workspace_dependencies` 给出，通常是
`~/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`），或者先 `pip3 install pillow numpy`。先 `python3 -c "import PIL, numpy"` 试一下，别等脚本报错。

## 流程（别跳第 1 步）

1. **先画框看位置**：`--preview` 只输出一张带红框的预览图，不改图。用 `view_image` 看一眼，确认框把水印连**投影**一起圈住了——投影没框进去，修完会留一圈灰边。
2. 确认位置后再正式跑，带上 `--check`。
3. **看 `--check` 的数字**：修复后框内高频残差 `max|hp|` 应该 < 2；如果还剩十几二十，就是没框全，回去调 `--box` / `--grow` 重跑。
4. 再把成品角部 crop 出来放大看一眼（`view_image`），确认没有灰印和补丁边界。指标 + 肉眼两道都要过。
5. 交付时说明：原图没动，结果在 `xxx_无水印.png`。

```bash
PY=~/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
S=~/.agents/skills/remove-watermark/scripts/remove_watermark.py

$PY $S 图.png --preview /tmp/prev.png        # 第 1 步：画框
$PY $S 图.png --check                        # 正式修，打印前后残差
$PY $S 图1.png 图2.png --check -o /tmp/out   # 批量，指定输出目录
```

## 参数

| 参数 | 用途 |
| --- | --- |
| `--preview PATH` | 只画框不改图（先看再改） |
| `--box L,T,R,B` | 手动指定水印外接框，含投影，宁大勿小 |
| `--corner tl/tr/bl/br` | 自动检测看哪个角，默认 `tl` |
| `--scope F` | 角部搜索范围占图片短边的比例，默认 `0.22` |
| `--grow N` | 检测框向外扩张像素，默认 `10` |
| `--margin N` | 填充用的固定边界宽度，默认 `16` |
| `--check` | 打印修复前 / 后框内高频残差 |
| `-o DIR` / `--suffix` | 输出目录 / 文件名后缀（默认 `_无水印`） |

自动检测只看一个角、且要求候选块（1）没顶到搜索区边缘、（2）对比度不高（< 80 级）。不满足就打印 `warning` 并**拒绝改图**——这是故意的，因为头发、五官这类内容会被误当水印。这时要么 `--preview` 看清楚后手动给 `--box`，要么换个 `--corner`。

手动量 `--box` 的办法：把角部 crop 出来放大看，同时用 numpy 找高亮像素的外接框（`np.where(lum > 背景 + 15)`），取并集后再外扩 10~20px。

## 踩过的坑

1. **别用模糊 / 涂白 / 贴个色块盖**：这类水印是「半透明底 + 白描边 + 白字 + 一圈投影」，糊完还会留灰印，轮廓照样看得见。
2. **别想阈值抠图再删**：水印本身是半透明的，抠不干净。
3. **自动检测为什么会只框到文字**：水印的底只是一层低对比度偏差（约 -10 级）。只用高阈值只能拿到描边和文字，修完会剩一圈灰边框。脚本用双阈值（高阈值取种子 → 低阈值长满整块）解决，自己手写时容易漏。
4. **奇数尺寸的坑**：多尺度求解时 `342 → 171 → 85 → 42`，上采样回来会差一列，必须补边（脚本里已处理）。
5. **输出不要覆盖原图**，默认另存后缀。
